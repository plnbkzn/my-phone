# My Phone — сайт с интерактивной демонстрацией

Это статический адаптивный сайт. Node.js и npm для публикации не нужны.

## Публикация на Netlify
1. Распакуйте архив.
2. Откройте https://app.netlify.com/drop
3. Войдите или зарегистрируйтесь.
4. Перетащите папку `my_phone_site` целиком (в ней должны быть `index.html`, `style.css`, `script.js`) в Netlify Drop.
5. После загрузки откройте выданную ссылку.

Чат использует демонстрационные ответы, заранее заданные в браузере. Это не подключённая AI-модель и не имеет доступа к телефону пользователя. Для настоящего AI нужен безопасный сервер и подключение модели.
